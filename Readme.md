


This is a dev enviorment for SoulCalibur VI not a release.

A few features used the SC6nepafu cheat engine script created by [@somberness](https://x.com/somberness) as a refrence

https://github.com/user-attachments/assets/e67cb9f5-c01f-49ba-a5d3-60775aaf33d9


## Features (highlights)

- Replay scrubbing: per-frame full-state snapshot ring (~49 MB at the default 5-second window) backed by SC6's own HgCpuDirect snapshot framework, surfaced as a "Replay" tab with a frame slider and ± step buttons. Captures while in the Replay viewer; seek freezes the world via the existing WorldTickGate.
