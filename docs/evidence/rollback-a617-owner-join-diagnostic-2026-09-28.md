# Bounded A617 owner-join diagnostic

The [preceding native/retained-log audit](rollback-a617-actor-impulse-phase-2026-09-28.md) found an A617 target physics actor but no exported join to the five captured ground children or its kinematic flag. The existing failure-only `Sc6ReplayHost.ParticleOwners.inl` diagnostic already compared the expired reference to captured physics actor rows. This change extends that same path; it does not admit a transaction or change task dispatch.

On a reconstruction-owner failure, the host now compares the failing reference with `operation.target->ground->meshes()` using both captured pointer and indexed weak identity, and logs the match and ground-mesh ordinal. For a matching captured physics actor it logs the captured component weak identity, copied body flag byte at `properties[0x9C]`, and the kinematic bit. It reads only retained checkpoint structures and does not dereference the expired UObject or native PhysX body. Pointer-only and indexed matches are separate so a stale or lazy weak identity is visible instead of silently treated as proof.
