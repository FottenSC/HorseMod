# Same-arrival correction grouping — 2026-09-28

The local correction schedule already accepts several ordered sample overrides in one request, and the rolling host admits one request per native tick. The qualification adapter previously parsed every wire row as a separate request and rejected equal arrival ticks. Its Python control planner also counted wire rows as revisions. That prevented one correction from changing two samples and could have misaligned independent controls if the parser alone were relaxed.

The adapter now groups consecutive rows with the same arrival, expected revision, and round into one request whose span points to an owned edit vector. Samples within a group must increase strictly; duplicate or reversed samples, changed revision/round at one arrival, and reversed arrivals reject before publication. The Python preflight, revision assignments, and independently authored control prefixes use the same arrival groups. Every edit remains represented in the authored native control.
