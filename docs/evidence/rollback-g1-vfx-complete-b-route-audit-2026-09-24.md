## What the existing owners actually cover

`Sc6ReplayVfxState::PreparedManager` owns the manager `+0x388` table as one of its published arrays, including displaced B backing. `Undo()` requires RecoverOriginal settlement, unchanged B fingerprint, valid leases, published C and B payload before `Write(false)`. This owns table storage, not arbitrary new callback receiver effects.

`Sc6ReplayTraceState` captures trace state `+0xD8`, controller/membership and attachment values, but attachment activation/deactivation headers `+0x1A8..+0x1C7` are immutable bindings. Capture requires empty delegate counts, exact attachment vtable and Deactivate/ShouldActivate/tick-setter targets. `Prepared::Undo()` calls B `ValidateBindings()` before any B publication: a changed attachment `+0x1B8` header is not an undoable value. Removing that check would not acquire callback backing or receiver state.

`NativeReplayPrerequisiteGuard::Selected` covers mesh contracts and trace root identities. Its root `manager` is **ALuxTraceManager** (vtable `143361F98`, component relation `+0x3A8`), not ALuxVFxInstanceManager (`143356F68`, BattleManager `+0x508`). Neither the VFX manager nor every runtime trace attachment is included merely by owning a root. The forwarding VFX observation wrappers are outside `Call`, intentionally providing no admission/undo protocol. Task-group admission is group5 only. The successful prerequisite protocol drains native execution and completed application before B recovery; it does not cancel or abandon a task. Host CPU settlement/reopen still requires idle executor, empty arena and completed interval/render state.
