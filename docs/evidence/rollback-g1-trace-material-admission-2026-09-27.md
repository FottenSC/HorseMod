# G1 trace-mesh material publication admission — 2026-09-27

## Scope and native basis

Astra Xhigh wrote this change with `desktop.daybreak-enabled.enabled=false`; root independently ran the tests and build. The existing trace state now rejects publication when either A or B has a nonnull effective material in a captured trace mesh. Admission reads the native mesh override array at `+0x808` and the mesh asset at `+0x910`; the asset's 0x30-byte material slots at `+0xA0` supply the slot count at `+0xA8`. A nonnull override wins, otherwise the asset slot is used. Reads are bounded and guarded; inconsistent or unreadable array shapes reject. The check runs in ordinary `Prepare` and the private/fresh-child publication paths before native writes. It does not dereference or claim ownership of the material. The [native contract](rollback-g1-finish-material-native-contract-2026-09-27.md) records the verified provider, vector setter, proxy task, and completion limits.

The boundary is deliberately conservative: any nonnull effective provider is unsupported, even if it is not a MID. It checks only captured A/B children at admission. A trace born later in Start, a provider replacement during native execution, and queued vector or resource-refresh tasks remain outside this proof. It is a fail-closed guard for one known unowned state domain, not B undo, a future-writer lease, or render/GPU settlement.
