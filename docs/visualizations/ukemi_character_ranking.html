Method and limits

Distance combines the currently resolved authored root displacement and native horizontal-velocity writers, using native route coordinates and character scaling. Any unresolved writer is shown as an incomplete route, never filled with a guessed character constant. Repeated-input results are withheld until the raw input-to-current-snapshot path is resolved. Pose-dependent hurtboxes, attack collision, walls, hit stop and opponent push are not included. Inferno is excluded.
